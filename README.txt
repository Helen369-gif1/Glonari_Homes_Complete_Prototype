GLONARI HOMES - ENGLISH CONTENT PROTOTYPE

OPEN
1. Extract the ZIP to a folder on your computer.
2. Open index.html in your web browser (or open the folder in VS Code and use Live Server).
3. Use the top navigation to visit all six pages.

UPDATING AN EARLIER COPY
1. Back up your existing glonari-homes-draft folder if you have edited it.
2. Copy the five updated secondary HTML pages and styles.css into the existing folder, replacing the old versions.
3. Copy any new files from assets/ into your existing assets/ folder.
4. Leave index.html untouched if you have customized your homepage.
5. Refresh your browser (Ctrl+F5 if needed).
